# 墨境｜培玲書法雲展

純 HTML、CSS、JavaScript 靜態網站。無框架、無前端執行期套件、無建置步驟。
網站目前涵蓋作品展廳、高解析觀看、分頁瀏覽、虛擬裝裱與場景圖下載。
尚未加入 Google 試算表、帳號、付款、訂單或會員系統。

## 開啟與預覽

用 VS Code 開啟整個專案資料夾。啟動本機 HTTP 伺服器：

```sh
python3 -m http.server 8000 --directory dist
```

在 Windows 若只有 `python` 指令，請將 `python3` 改成 `python`。
用瀏覽器開啟 `http://localhost:8000`。也可使用 VS Code Live Server，將根目錄設為 `dist`。
不要直接雙擊 HTML：本網站使用 JavaScript modules 與 JSON，需透過 HTTP 載入。

若已安裝 Node.js，也可以使用 `npm run serve`。這個指令仍需要 Python。
**沒有 `npm install` 或 `npm run build` 的必要步驟。**

## 虛擬裝裱

「裝裱形式」可切換木框與掛軸。木框提供胡桃木色與原木色；兩種形式均可搭配米白或暖灰裱料。掛軸提供「素雅留白」「圓角襯底」「錯位疊襯」「立體折邊」四款。後三款參考使用者裝裱老師提供的 IMG_8864、IMG_8862、IMG_8869 照片，僅以程式重現裝裱結構的搭配示意；不使用參考照片內的他人書法。樣式名稱是網站辨識名稱，不是裝裱工法定名。各樣式在預覽及下載共用 `scrollStyles` 與繪圖邏輯。

基本掛軸採天頭較寬、地腳較窄的示意比例，依原圖長寬比完整顯示作品；在較窄場景自動縮小以免溢出。場景與下載 PNG 共用 `scroll.js`，不重繪作品筆觸。尺寸仍是搭配示意，非實際裝裱尺寸。

## 新增一件一般作品

1. 將完整作品影像與精選局部放入 `dist/assets/works/作品代號/`。
2. 在 `dist/data/artworks.json` 的陣列加入一筆作品資料，代號不可重複。
3. 執行檢查，再在本機查看新卡片與作品頁。

卡片、作品頁、其他作品連結與可試掛作品選單，都會依這份資料自動更新。
請使用既有資料作為欄位範本；一般作品設定 `pages: null`，沒有圖塊時可省略 `pyramid`。

```json
{
  "id": "new-work",
  "title": "作品名稱",
  "author": "康培玲",
  "year": "2026",
  "format": "直幅",
  "medium": "2026 · 直幅",
  "caption": "康培玲 · 2026",
  "overview": "assets/works/new-work/overview.webp",
  "description": "一句簡介。",
  "source": "掃描影像。",
  "note": "創作心得，可留空。",
  "noteCredit": "康培玲・創作自述",
  "size": "紙本 70 × 140 公分",
  "pages": null,
  "studio": true,
  "studioHeight": 40,
  "studioTop": 5,
  "poster": {
    "src": "assets/works/new-work/poster.webp",
    "className": "poster-standard",
    "alt": "作品局部的簡短描述。",
    "position": "50% 50%",
    "scale": 1.03
  },
  "tags": ["直幅"]
}
```

`poster` 控制入口的局部焦點；`overview` 是點入後的完整作品，兩者各自設定。
`studioHeight`、`studioTop` 是場景中的示意百分比，不是實際尺寸校準。
含既有實體畫框、或尚不適合試掛的影像可設定 `studio: false`。

## 製作高解析影像與分頁

僅影像處理需要 Pillow：`python3 -m pip install -r requirements.txt`。
把原始掃描另存於自己保管的 `originals/`，該資料夾不會納入 Git；現有網頁影像已完整隨專案提供。

```sh
python3 scripts/prepare_artwork.py originals/new-work.tif --id new-work --tiles
```

工具將建立 `assets/works/new-work/` 及 `data/new-work-pages.json`。
若有分頁，先建立一份按正確閱讀順序排列的裁切座標 JSON：

```json
[[100, 100, 500, 1500], [600, 100, 1000, 1500]]
```

座標單位為原圖像素，依序為左、上、右、下。範例座標必須換成實際影像的範圍。
搭配 `--page-boxes page-boxes.json`；局部入口可搭配 `--poster-box 左 上 右 下`。
工具拒絕覆寫已存在的作品代號，不會自動加入作品資料或發布網站。

作品資料填入：

- 有圖塊時：`"pyramid": "data/new-work-pages.json"` 與 `"tileBase": "assets/works/new-work/tiles/"`。
- 有分頁時：另填 `"pages": "data/new-work-pages.json"`，並補 `readingOrder`。
- 只有高解析整圖、沒有分頁時：`pages` 維持 `null`。

王鐸唐詩的既定順序為上、中、下排，各排從右到左，1–15 頁。
每頁的 `page`、`label` 與 `url` 在分頁資料裡維護，不要為翻頁修改觀看器程式。

王鐸唐詩另以 `supplementalViews` 附上冊頁封面、近觀與展開全景，接續在 15 頁掃描之後，可共用左右箭頭與縮圖切換。原掃描分頁、圖塊資料及首頁主視覺維持原有設定。

新增水墨山水（IMG_2958.JPEG）以觀看範圍裁去左側墨水瓶，保留完整紙張、筆墨、落款與印章；原始照片保留。花氣帖入口使用 `poster-flower-ink`，將原作書法照片以 CSS multiply 疊在淡雅水墨花影背景上，不生成或改寫書法字跡。採用 `dist/assets/works/flower/ink-background-v1.png`：暖米色宣紙、低對比柔和花影、中央留白，背景無文字、印章與標誌，由內建 ImageGen 製作。作者確認此版本更適合「花氣薰人」的詩意。

作者山水畫 IMG_2958.JPEG 衍生的山石淡墨底圖另保留於 `dist/assets/works/flower/ink-background-own-landscape-v2.png`，目前不套用在任何作品入口，留待搭配其他書法。該圖由內建 ImageGen 渲染，提示重點為保留原畫平頂山石、直立山石與疊石、左下樹叢、右下屋舍及留白、淡化墨色、無題字或印章。原畫展示保留完整落款與印章。

## 修改樣式的規範

CSS 載入順序固定為 reset → base → 該頁專用樣式。

- 色彩與字體先修改 `base.css` 的 `:root` 變數。
- 共用元件放在 `base.css`；作品頁只修改 `work.css`，首頁只修改 `index.css`。
- 找到原規則再修改，避免一直在檔尾新增覆寫。響應式規則與對應區塊一起檢查。
- 斷點延續現有 Desktop-First；不為套用特定教學範例而更換已確認的版面。
- 圖片共用 `display: block` 與 `max-width: 100%`，完整縮圖採 `object-fit: contain`。
- 原始筆墨影像不重新生成；場景可以替換，作品本身保持獨立合成。
- 保留 viewport、鍵盤焦點、圖像替代文字及減少動態效果的支援。
- 尚無圖示字型需求，因此沒有加入 Material Symbols 的外部依賴。

## 筆墨動態試作

獨立體驗頁為 `dist/depth.html`，可用 `?art=flower` 或 `?art=wang` 選擇初始作品。

花氣帖採完整字跡（含左側字行、落款與印章）偏左配置、右側留白墨流的原創構圖；依視窗尺寸等比例配置，不伸縮字形。書法取自作者自己的完整照片，以 [.19,.14,.885,.94] 保留全部書寫內容，只排除作品外的鎮紙與環境；偏側構圖只調整整幅的位置及等比例尺寸，不裁掉文字，使用局部紙色估計遮罩抑制拍照紙面灰影，原始照片不覆寫。襯底重新使用已確認的生成淡墨花影 `assets/works/flower/ink-background-v1.png`，以 0.62 透明度及 multiply 疊在宣紙底色上；花影位於流動墨韻與完整書法下方。紙紋、墨團、分層擴散及位移墨絲由程式製作，這個體驗頁不使用故宮海報、館徽、日期、展覽文字或海報影像素材。參考圖僅供理解偏側構圖與留白方向。字跡保持靜定；`ink-motion.js` 的 `InkDiffusion` 使用三個集中在右側的墨滴來源及內外擴散濃度層，做輸送、擴散與較強的注墨，配合 `ink-water-filter` 的位移紋理形成墨絲與邊界流動。濃度比舊版更易察覺；可暫停、重新暈染、靜態對照及調濃淡。花影保持靜定，動態由原有墨流呈現；靜態對照只隱藏墨流，保留同一幅花影與書法。這是視覺意象，非流體量測。

王鐸唐詩目前只顯示第七頁右側「楓林」局部的原始掃描裁切（`assets/leaf-1-3.webp`），沒有字跡分離或推測的書寫動畫。作者已指出舊版筆順錯誤；播放與進程控制在此模式隱藏並停用，不再載入 `wang-writing.json`。要忠實呈現實際行筆，須依作者示範或核定的筆順另行製作。舊試驗路徑及產生器留在來源供研究，但不是已核定筆順、不可重新套用作書寫示範。

`depth.js` 管理載入、作品切換、花氣帖播放及對照；分頁隱藏時停止動畫，減少動態偏好預設靜態，只有明確按播放／重播才啟動。畫面更新約 30 fps，不用外部套件或相機權限。

驗證包含濃度場擴散與重置、切換、重播、對照、減少動態偏好，以及王鐸不啟動書寫模擬的防退化檢查。以實際濃度場繪製時間點分格檢視；完整瀏覽器及手機實機觀感尚未驗證。
